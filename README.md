# py_whole

Single-file offline web notebook project.

## Purpose

This repository will build a self-contained browser application delivered as a single HTML file with embedded JavaScript and WebAssembly. The app will provide a Jupyter-compatible notebook environment that runs entirely offline in modern browsers.

## Current Status

Requirements have been captured and organized into a phased roadmap in:

- `docs/requirements.md`
- `docs/roadmap.md`

An initial implementation scaffold now exists in:

- `src/`
- `scripts/build_single_html.sh`
- `dist/py_whole.html` after building

## Initial Product Direction

- Browser-only execution with no network dependency at runtime
- Python runtime via WebAssembly, using Pyodide if it satisfies the all-in-browser constraint
- Single-file HTML deliverable, generated by a separate build pipeline if needed
- First proof of concept focused on rich notebook editing and Python execution for a single notebook

## Build

Build the current single-file artifact with:

```bash
bash scripts/build_single_html.sh
```

This writes:

- `dist/py_whole.html`

## Implementation Status

The current implementation provides:

- a notebook-style single-page UI
- add/run/delete/reorder code cells
- markdown cell creation and cell type toggling
- notebook autosave and recovery via browser storage
- `.ipynb` import and export
- embedded Pyodide core runtime for offline Python execution
- dark-mode presentation
- packaged scientific-library inventory in the sidebar
- a runtime adapter seam for the future broader scientific package set

The current implementation now embeds the Pyodide core runtime into the generated HTML and can execute basic Python code offline after runtime initialization.

Current limitations:

- the bundled scientific subset now includes `numpy`, `scipy`, `pandas`, `sympy`, and the `matplotlib` dependency chain
- the package sidebar still includes planned packages that are not yet embedded
- runtime restart currently reloads the page because Pyodide supports only one runtime instance per JavaScript global scope
